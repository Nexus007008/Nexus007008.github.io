# nexus007008.github.io

Einfache, moderne Landingpage für GitHub Pages.

## So geht's online

1. Gehe auf [github.com/new](https://github.com/new)
2. Repository-Name: **`Nexus007008.github.io`** (muss exakt so heißen!)
3. Auf **Public** stellen und erstellen
4. Alle Dateien aus diesem Ordner hochladen:
   - `index.html`
   - `style.css`
   - `script.js`
5. Fertig! Die Seite ist in 1–2 Minuten erreichbar unter:

   **https://nexus007008.github.io**

## Anpassen

- Texte ändern → `index.html`
- Farben & Design → `style.css` (oben bei `:root`)
- Links zum GitHub-Profil sind schon eingetragen

Viel Spaß! 🚀
